# Досье

Приложение для Windows 10/11 x64: поиск российских организаций и ИП непосредственно в ФНС, официальные выписки, опубликованные телефоны, почта, сайты и сбор доступных сведений внутри приложения. **API-ключ и подписка не требуются.**

## Скачать

Готовые EXE: **[GitHub Releases → Assets](https://github.com/Randupy/checker-ooo/releases)**. В версии **1.2.0** добавлены контакты в карточке: телефоны, факсы, электронная почта и сайты, с источником и датой получения. API-ключи и подписка не требуются. Исправления прямого поиска ФНС из 1.1.0 сохранены.

- `Dosye-…-Setup-x64.exe` — установщик с выбором папки и ярлыком.
- `Dosye-…-Portable-x64.exe` — переносимая версия без установки.
- `SHA256SUMS.txt` — контрольные суммы.

Состояние новых сборок: [GitHub Actions](https://github.com/Randupy/checker-ooo/actions). Ссылки `/workspace/...` относятся к рабочей папке облака, а не к публичному скачиванию.

## Как пользоваться

1. Введите название, ИНН, ОГРН или ОГРНИП. Приложение отправит поисковую форму непосредственно в ЕГРЮЛ / ЕГРИП ФНС и покажет найденные организации. Если результатов много, нажмите **Показать ещё организации**. Контрольные цифры номера проверяются до запроса. Записи без опубликованного ИНН также отображаются, если ФНС предоставила ОГРН.
2. Откройте организацию. Сверху появится раздел **Контакты для связи**. Сначала проверяются выписка ФНС и деловые справочники; найденные телефоны, факсы, почта и сайты появляются по мере получения. Каждый контакт можно скопировать. Нажмите название источника, чтобы открыть соответствующую запись внутри приложения. Кнопка **Найти контакты / Обновить контакты** запускает только проверку контактных источников, без ожидания остальных реестров.
3. Во вкладке **Выписка ФНС** нажмите **Загрузить выписку бесплатно**. Официальный PDF появится прямо в карточке; его можно сохранить на диск. В выписке доступны полные опубликованные разделы: учредители, виды деятельности, регистрационные изменения и другие сведения.
4. В разделе **Сведения из источников** раскройте полученный результат. Если сайт запросил CAPTCHA, регион или подтверждение формы, нажмите **Открыть здесь**, завершите поиск внутри приложения и выберите **Сохранить сведения**. Внешний браузер не запускается.
5. Сохраните карточку в избранное или экспортируйте её в JSON/CSV. Полученные страницы и таблицы включаются в экспорт и сохраняются после перезапуска.

Кнопка **Посмотреть пример** показывает явно обозначенную вымышленную организацию. Пример никогда не используется вместо результата реального поиска и не запускает запросы в реестры.

## Что получает приложение

| Источник | Получение и отображение |
| --- | --- |
| ЕГРЮЛ / ЕГРИП ФНС | Прямой бесплатный поиск с пагинацией, нормализованные реквизиты, исходные поля записи |
| Выписка ФНС | Подготовка и загрузка официального PDF, просмотр в карточке и сохранение |
| ГИР БО | Поиск по ИНН, переход в найденную запись, сбор доступного текста и таблиц страницы |
| Прозрачный бизнес, реестр МСП | Автоподстановка в распознанную форму, сбор открытой страницы, встроенное окно для дополнительных параметров |
| Картотека арбитражных дел, ФССП | Поиск в форме источника и сохранение доступной выдачи; регион и другие обязательные поля уточняются внутри приложения |
| ЕФРСБ, Федресурс | Открытые страницы, сообщения и таблицы; проверка источника при необходимости выполняется в его встроенном окне |
| ЕИС Закупки, РНП | Переход с поисковым запросом, получение опубликованной выдачи внутри приложения |
| Лист-Орг | Переход из поиска по ИНН в точную карточку, опубликованные телефоны, факсы, почта и сайты |
| Руспрофайл, Чекко | Только доступная без подписки информация публичных страниц; платные API не используются |

Это не обещание доступа ко всем существующим базам или закрытым сведениям. Прямой адаптер JSON реализован для ФНС; для остальных сервисов используется изолированный Chromium: форма поиска, опубликованный текст и таблицы, а не платный API. Формы сайтов могут изменяться. Не каждая форма распознаётся автоматически, и дополнительные параметры нельзя достоверно угадать.

Каждый источник имеет отдельный результат: **сведения получены**, **не найдено**, **CAPTCHA**, **нужно уточнить поиск**, **недоступен**. Наличие формы или заполненного поля не считается найденными данными. Снимок страницы ограничен размером; сокращение явно отмечается в результате. CAPTCHA не решается автоматически. Сбой соединения не означает отсутствия долгов, дел или организации.

Поисковая запись ФНС не содержит всех полей и сама по себе не доказывает действующий статус: приложение показывает **Запись в реестре ФНС**, а не выдумывает статус или рейтинг надёжности. Полные разделы смотрите в выписке. Сохранённая карточка — снимок с датами получения; для актуализации выполните поиск или сбор заново.

## Контакты

Контакты извлекаются из карточки с совпавшими реквизитами и наименованием. Одноимённая организация, первый случайный результат, телефон поддержки справочника, футер и соседние компании не считаются контактами выбранного контрагента. Факсы отмечаются отдельно. Дубли объединяются с сохранением нескольких источников и дат.

ФНС не публикует телефоны в поисковой записи. Для зарегистрированной электронной почты приложение дополнительно читает специальный раздел в начале официальной PDF-выписки. В справочниках проверяются открытые контактные блоки и метаданные организации. Скрытые/неполные значения не восстанавливаются. При CAPTCHA или отказе доступа источник остаётся непроверенным; его можно открыть и подтвердить внутри приложения.

Показываются только опубликованные деловые контакты: у некоторых организаций и закрытых ИП их может не быть. Дата получения страницы не подтверждает, что номер или почта ещё используются. Контакты сохраняются в карточке, избранном и JSON/CSV вместе с происхождением. Старые сохранённые карточки совместимы с новой версией; при открытии карточки без проверки контактов сбор запускается автоматически.

## Разработка

Node.js **22.19+** или **24 LTS**, npm. Для обычного запуска Electron нужна графическая среда.

```sh
npm ci
npm run setup:desktop
npm run dev
```

Electron 45 устанавливает бинарный runtime отдельной командой `setup:desktop`. При установке через стандартный HTTP(S)-прокси задайте `ELECTRON_GET_USE_PROXY=1`. Проверки TLS и контрольных сумм не отключаются.

Веб-предпросмотр:

```sh
npm run dev:web
```

В нём доступны интерфейс, пример, история, избранное и экспорт. Прямые запросы и встроенные окна источников работают в настольном приложении. Предпросмотр не выдаёт фикстуры за живые результаты и не открывает внешний браузер.

## Проверки

```sh
npm run build
npm test
npx playwright install chromium
npm run test:e2e
npm run test:desktop
npm run test:live       # реальный поиск и выписка ФНС, нужен доступ к сайту
```

Модульные тесты проверяют ИНН/ОГРН, протокол ФНС, ожидание и пагинацию, CAPTCHA и ошибки, выдачу PDF, хранение и экспорт. Браузерные сценарии проверяют интерфейс, поиск, отсутствие поля платного ключа, встроенную панель и разбор DOM. Настольный тест запускает настоящий Electron: запрос через IPC, изолированный WebContentsView, получение документа, сохранение результатов, экспорт и перезапуск.

Протокольные ответы в тестах — **фикстуры**, не подтверждение актуальности реальных данных или доступности сайтов из вашей сети. Для живой проверки выполните поиск по действующему ИНН в настольном приложении и откройте выписку. В облаке нужно разрешить исходящие соединения к соответствующим доменам ФНС и другим реестрам; CONNECT 403 от сетевого прокси — ограничение среды, не ответ самого реестра.

В Linux без графической среды настольный тест использует headless и `--no-sandbox` только в тестовом процессе. Обычное приложение сохраняет песочницу. Для системного Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium` вместо загрузки браузера.

## Сборка Windows

```sh
npm run dist:win       # NSIS и portable; рекомендуется Windows
npm run dist:portable  # только portable
```

Файлы появляются в `release`. Упаковщик запускается с `--publish never`: публикацию выполняет отдельный шаг GitHub Actions. Push тега `v*` после успешных проверок Linux и Windows прикрепляет EXE и контрольные суммы к GitHub Releases. Обычный push ветки создаёт артефакты проверки и сборки.

Сборка по умолчанию не подписана сертификатом издателя. Для подписи используйте стандартную конфигурацию electron-builder и секреты CI; закрытые ключи не хранятся в репозитории.

Для NSIS при кросс-сборке нужен работающий Wine. В текущем Linux-образе Wine toolset не запускает `ntdll.dll`, поэтому полный установщик собирается на Windows runner. Portable собирается и в Linux.

В облачной среде с домашней папкой только для чтения:

```sh
bash scripts/setup-cloud.sh
XDG_CACHE_HOME=/tmp/checker-xdg-cache ELECTRON_BUILDER_CACHE=/tmp/checker-builder-cache npm run dist:portable
```

Для быстрой кросс-сборки можно задать `ELECTRON_BUILDER_COMPRESSION_LEVEL=3`.

## Хранение и безопасность

- Основной renderer изолирован, работает без Node.js и с включённой песочницей. IPC проверяет отправителя и аргументы.
- Страницы источников загружаются в отдельный `WebContentsView` без preload-моста приложения и без Node.js. Их навигация ограничена HTTPS-доменами выбранного источника; произвольные URL не передаются системной оболочке.
- Поисковый запрос подставляется в распознанное поле, нажимается только кнопка поиска. Форма входа, пароль, CAPTCHA и платежи не заполняются автоматически.
- В карточку переносится текст и массивы ячеек, а не исполняемый HTML. Результаты проверки CAPTCHA не подменяются и не генерируются приложением.
- История, до 200 избранных и до 50 недавних карточек находятся в `state.json` в `%APPDATA%\Dosye`. Запись последовательная и атомарная. Повреждённый существующий файл автоматически не перезаписывается.
- Старые карточки версии 1.0 сохраняются. Прежний зашифрованный ключ не используется и не удаляется без действия пользователя. Для новой версии он не нужен.
- Анонимные сессии источников находятся в отдельном профиле `persist:dosye-official`. Стандартный HTTP(S)-прокси среды поддерживается; в Windows без него Chromium использует системные сетевые настройки.
- Сайты источников получают реквизиты запроса и могут загружать свои ресурсы и аналитику. У приложения нет собственного сервера поиска или аналитики. Шрифты поставляются локально.
- PDF загружается только из ФНС, проверяются сигнатура и лимит 20 МБ. CSV использует UTF-8 BOM и `;` для Excel; формулы из внешних данных нейтрализуются. JSON сохраняет регистрационную запись, результаты источников и время их получения.

## Структура

```text
electron/free-registry.ts     Бесплатный протокол поиска и выписки ФНС
electron/extract-contacts.ts  Зарегистрированная почта из PDF
src/shared/contact-dom.ts    Переход в нужную карточку и чтение контактов
src/ContactsPanel.tsx        Контакты с происхождением и датами
electron/source-workspace.ts  Изолированные окна и сбор открытых страниц
electron/main.ts             Жизненный цикл, IPC, сохранение документов
electron/storage.ts          Локальная история и карточки
src/                         Интерфейс, выписка, сводка и окно источника
src/shared/                  Схемы, каталог, DOM-обработчики и экспорт
tests/                       Модульные, браузерные и настольные проверки
```
